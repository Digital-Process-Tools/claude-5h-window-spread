- Renamed the plugin ID from `claude-5h-window-spread` to `5h-window-spread` (#19). The `claude-` prefix is reserved for Anthropic's own plugins and `claude plugin validate --strict` rejects it, which broke the v0.3.1 release. **This breaks existing installs**: run `/plugin uninstall claude-5h-window-spread@dpt-plugins` then `/plugin install 5h-window-spread@dpt-plugins` to pick up the new name.
